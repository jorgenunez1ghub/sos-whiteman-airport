# Whiteman Airport Systems Transformation Framework

Initialized: 2026-06-09

This repository organizes a systems-level study of Whiteman Airport in Pacoima, CA. It is designed for evidence-backed analysis, not loose note-taking.

The working frame is:

> What is the highest-value long-term configuration of this regional infrastructure asset under federal, political, environmental, safety, economic, and community constraints?

## Folder Structure

```text
00_project/        Charter, assumptions, decision log, research backlog
01_sources/        Registered source material and source notes
02_analysis/       Core analytical workstreams
03_data/           Raw, interim, processed, external, and GIS data
04_models/         Decision, GIS, simulation, digital twin, and financial models
05_outputs/        Briefs, reports, decks, dashboards, and graphics
06_templates/      Reusable templates for repeatable analysis
07_archive/        Retired drafts and superseded materials
```

## Working Rules

1. Register sources before relying on them.
2. Keep raw source files unchanged in `03_data/raw/` or `01_sources/`.
3. Put interpretation in `02_analysis/`, not in raw-data folders.
4. Track assumptions, decisions, and unresolved risks in `00_project/assumptions_decisions_risks.md`.
5. Build deliverables from analysis outputs, not directly from unverified notes.
6. Prefer primary sources: County, FAA, NTSB, board records, contracts, official study materials.
7. Label advocacy, media, AI-generated, and secondary sources clearly.

## Current Analysis Thesis

The Whiteman Airport question should not be treated as only "close versus keep open." The stronger framing is a systems transformation problem involving:

- FAA and grant-assurance constraints
- aviation network and emergency-response dependencies
- public health and environmental justice concerns
- land-use, housing, and redevelopment value
- fiscal, operational, and legal transition risk
- stakeholder legitimacy and governance design
- digital twin and dashboard-enabled decision support
