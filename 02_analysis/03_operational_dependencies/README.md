# Operational Dependencies

Purpose: identify what depends on the airport and what would be affected by each alternative.

Analyze:

- aircraft operations
- based aircraft
- runway/tower/airspace dependencies
- flight schools and maintenance businesses
- emergency services and public agency operations
- regional airport network capacity
- roadway, rail, and land-use adjacency
- utilities, hazards, and safety areas

Primary outputs:

- dependency map
- continuity-of-operations questions
- closure/transition dependency table
