# Safety and Incident Timeline

Purpose: create a fact-based safety timeline that separates verified incident data from public perception.

Analyze:

- NTSB records
- FAA data
- local emergency-response records
- media reports
- community testimony
- runway, approach, and obstruction context
- mitigation history

Primary outputs:

- incident timeline
- safety claims matrix
- verified/unverified claim table
- mitigation implications
