# PMO Dashboard

Purpose: define how a PMO or study office would monitor scope, schedule, risk, sources, and decisions.

Dashboard areas:

- study schedule
- source validation status
- risk register
- alternatives comparison
- public engagement status
- FAA/legal dependency status
- data completeness
- decision-gate readiness

Primary outputs:

- metric catalog
- dashboard wireframe
- cadence and reporting model
- executive scorecard
