# Analysis Workstreams

This folder holds interpretation, synthesis, and analytical products.

Use `00_synthesis/analysis_plan.md` as the operating guide. Each numbered folder corresponds to a core workstream from the Whiteman Airport Systems Transformation Framework.

## Output Standard

Each workstream should eventually include:

- A short issue brief
- Source notes with IDs from `01_sources/source_register.csv`
- Key findings
- Open questions
- Data needs
- Dependencies on other workstreams
- Implications for alternatives analysis
