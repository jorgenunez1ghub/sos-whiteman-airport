# Economic and Land Use

Purpose: compare aviation value, redevelopment value, community value, and fiscal value.

Analyze:

- existing aviation economic activity
- jobs and businesses
- County revenue and costs
- affordable housing feasibility
- market constraints
- infrastructure costs
- opportunity cost
- land value versus infrastructure value
- workforce and local hiring potential

Primary outputs:

- economic impact issue brief
- land-use alternatives table
- fiscal model requirements
- redevelopment feasibility questions
