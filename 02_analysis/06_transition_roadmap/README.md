# Transition Roadmap

Purpose: define what must happen before, during, and after any transformation decision.

Phases:

- Phase 0: evidence baseline
- Phase 1: requirements and constraints
- Phase 2: alternatives and decision gates
- Phase 3: pilots and mitigation actions
- Phase 4: implementation planning
- Phase 5: long-term governance and monitoring

Primary outputs:

- phased roadmap
- decision gates
- dependencies
- no-regret actions
- off-ramps and reversal points
