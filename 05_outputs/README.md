# Outputs

Use this folder for materials intended for readers.

## Subfolders

- `briefs/`: short memos and decision briefs
- `reports/`: long-form reports
- `presentations/`: slide decks
- `dashboards/`: dashboards and scorecards
- `graphics/`: diagrams, maps, and visual exports

Best practice: every output should cite source IDs from `01_sources/source_register.csv`.
