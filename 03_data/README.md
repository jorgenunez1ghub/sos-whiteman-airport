# Data

Use this folder for datasets and derived analytical tables.

## Subfolders

- `raw/`: original unmodified datasets
- `interim/`: cleaned but not final working data
- `processed/`: analysis-ready data
- `external/`: third-party datasets
- `gis/`: geospatial files, shapefiles, GeoJSON, rasters, maps

Rules:

- Do not manually edit raw data.
- Document transformations in notebooks, scripts, or source notes.
- Keep sensitive or restricted data out of Git unless explicitly approved.
