# Sources

Use this folder for source collection and source notes.

## Source Rules

- Add every meaningful source to `source_register.csv`.
- Store source files in the matching subfolder when local copies are needed.
- Do not edit raw source files.
- Add extraction notes separately if a PDF, article, transcript, or dataset needs interpretation.
- Mark each source as official, stakeholder, media, advocacy, secondary, or AI-generated.

## Subfolders

- `county/`: LA County motions, board letters, study materials, public meeting files
- `faa/`: FAA AIP, grant-assurance, NPIAS, closure/release, and correspondence materials
- `ntsb/`: incident and accident reports
- `media/`: news coverage
- `advocacy/`: aviation, community, public health, environmental justice, and other advocacy materials
- `web/`: captured public web pages and source notes
- `shared-chat/`: user-provided shared-chat context and extraction notes
