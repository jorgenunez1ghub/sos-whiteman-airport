# Models

Use this folder for analytical models and scenario tools.

## Subfolders

- `decision_model/`: scoring, weighting, MCDA, and alternatives analysis
- `gis/`: geospatial analysis models
- `simulation/`: operations, traffic, or scenario simulations
- `digital_twin/`: digital twin concept models and prototypes
- `financial_model/`: cost, revenue, funding, and redevelopment scenarios

Every model should include:

- input sources
- assumptions
- outputs
- limitations
- validation notes
